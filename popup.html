How it works
  1. Everyone installs the FaceParty extension.
  2. Open the same streaming site (Netflix, YouTube, etc.) with Teleparty.
  3. One person taps Create room and shares the invite link.
  4. Friends paste the link here and tap Join.
  5. Webcams open in a floating FaceParty window (so the camera works).

No account, no server bill — FaceParty uses PeerJS’s free public broker for signaling and WebRTC for peer-to-peer video. Best for 2–6 people.
